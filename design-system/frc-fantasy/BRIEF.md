# FRC Fantasy — UI implementation brief

Source of truth: `MASTER.md` in this folder (generated by UI/UX Pro Max). This brief turns it into
rules an implementer can apply directly in Next.js 16 + Tailwind 4. **It overrides the plain Tailwind
class strings in the Part 3 plan tasks.** Behaviour, spec text, and tests from the plan stay exactly as
written; only the look changes.

## Goal

It should feel like a real fantasy-sports product (think ESPN Fantasy / Sleeper), tuned for a
robotics-competition crowd: bold, energetic, high-contrast, mobile-first at 360px, and readable by a
grandparent between matches. Not a generic Tailwind demo.

## Foundation (Task 22b builds this; later tasks only consume it)

```css

  --color-red-alliance: #dc2626;   /* FRC red, used sparingly (danger, red alliance) */
  --color-bg: #eff6ff;             /* page background */
  --color-surface: #ffffff;        /* cards */
  --color-surface-2: #f1f5fd;      /* muted panels, table stripes */
  --color-fg: #0f172a;             /* text */

  --color-success: #15803d;

  --font-body: var(--font-barlow), "Barlow", system-ui, sans-serif;

  --radius-pill: 9999px;
  --shadow-card: 0 1px 2px rgb(15 23 42 / 0.06), 0 8px 24px -12px rgb(37 99 235 / 0.25);
```

Use these tokens as Tailwind utilities (`bg-bg`, `text-fg`, `bg-primary`, `text-accent`, `font-display`,
`rounded-card`, `shadow-card`). **No raw hex in components.**

### Fonts

`next/font/google`: `Barlow_Condensed` (weights 500, 600, 700) as CSS variable `--font-barlow-condensed`
and `Barlow` (400, 500, 600) as `--font-barlow`, applied on `<html>` in `app/layout.tsx`. Headings and big
numbers use `font-display`; body uses `font-body`. Base size 16px, line-height 1.5, tabular numerals for
scores (`tabular-nums`).

### App shell (`app/layout.tsx`)

- Sticky top bar, `bg-primary text-on-primary`: left a small SVG mark (a simple hexagon/gear glyph,
  inline SVG) + "FRC FANTASY" in `font-display` uppercase tracking-wide; right side is empty in v1.
- Content column `max-w-2xl mx-auto px-4 pb-24` on `bg-bg`; on ≥ md widen to `max-w-3xl`.
- Footer: one muted line, "Scores from The Blue Alliance", linking to thebluealliance.com.
- Respect `prefers-reduced-motion`: all transitions are `motion-safe:` only.

### Shared primitives (`components/ui/`)

Keep them tiny and typed. Each file one component.

- `Card.tsx` — `bg-surface rounded-card shadow-card border border-border p-4`; optional `title`,
  `eyebrow` (small uppercase `text-fg-muted`), `action` (right-aligned node).
- `Button.tsx` — variants `primary` (blue), `accent` (gold, dark text), `secondary` (white with border),
  `danger` (red text + red border), `ghost`; sizes `md` (`min-h-11 px-4`) and `sm` (`min-h-9 px-3`);
  always `rounded-pill font-semibold cursor-pointer motion-safe:transition-colors duration-200
  focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 disabled:opacity-50`.
  Accepts an `href` prop that switches rendering to `next/link`.
- `Badge.tsx` — pill; `tone`: `neutral | live | upcoming | final | drafting | warning`. `live` is
  green with a pulsing dot (`motion-safe:animate-pulse`).
- `Input.tsx`, `Select.tsx` — `h-11 w-full rounded-lg border border-border bg-surface px-3
  focus-visible:ring-2 focus-visible:ring-ring`; visible `<label>` above, error text below in red.
- `Alert.tsx` — `tone`: `info | success | warning | danger`; role="status"/"alert".
- Icons: inline SVG from Lucide (paste the path data; no icon package needed, no emoji).

### Leaderboard treatment (the hero of the product)

- `components/Leaderboard.tsx`: rows are cards-in-a-list. Rank in a circle: gold for #1, silver
  (`bg-slate-300`) for #2, bronze (`bg-amber-700 text-white`) for #3, `bg-surface-2` for the rest.
  The total is big (`font-display text-2xl`) in `text-primary`; rank-1 row has a subtle gold left border.
- Per-round mini breakdown under the name in `text-fg-muted text-xs tabular-nums`.
- Season standings and round leaderboard share this component.

### Round page

- Header block: event name in `font-display text-3xl uppercase`, dates, status badge, TBA link as a
  small secondary button, freshness line.
- Rosters: `<details>` cards; the summary shows an avatar-style circle with the player's initial, name,
  team count, big total. Expanded breakdown: each team is a mini row with team number in a
  `font-display` chip and the nickname; category lines are a two-column list (label left, `+21` right,
  gold for positive, red for negative).
- Draft board: the plan's wrapped grid, but cells are chips: `#7 · Mom` small muted, team number
  `font-display text-lg`. Empty cells dashed.
- Adjustments: card list with the reason in body text and the points on the right in gold/red.

### Admin pages

- Same shell plus a "Commissioner" eyebrow in violet. Sections are `Card`s with clear titles.
- Draft entry: the banner ("Pick 7 of 20 — Mom's turn (round 2)") is a full-width `bg-primary`
  card with `font-display text-2xl` text. Available teams are a 2-column grid of tappable chips
  (`min-h-12`) with the number big and nickname small; tapping gives an immediate pressed state.
- Every destructive action uses the `danger` button and (for round delete) `window.confirm`.

### Home page

- Hero: "FRC FANTASY" in `font-display text-5xl`, one-line pitch, three benefit bullets with Lucide
  icons (Trophy, Activity, Users), then the Create League card. Background: `bg-bg` with a soft
  radial gradient of primary→transparent at the top (CSS only).

## Non-negotiables (from the plan + UX rules)

- 360px width: no horizontal scroll; long names `truncate` inside `min-w-0`.
- Tap targets ≥ 44px (`min-h-11`); 8px+ between adjacent tappables.
- Contrast ≥ 4.5:1 for text (use `text-fg-muted`, never `text-slate-400` on white for body text).
- Visible focus rings; `cursor-pointer` on everything clickable.
- Loading and error feedback on every admin action (busy state on buttons, `Alert` on error).
- Transitions 150–300ms and only under `motion-safe:`.
- Zero-point lines hidden from breakdowns (spec §7.9); never pass `LeagueRow` to a client component.
